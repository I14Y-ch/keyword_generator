    DCAT-AP CH Keyword Priority Cascade

    According to the DCAT-AP CH 2.0 specification, keywords should be sourced in the following priority order:

    1. TERMDAT - Swiss federal terminology database (highest priority)
    2. GEMET - Environmental terminology for geo-related context
    3. Wikidata - General knowledge base
    4. Literal keywords - Plain text as last resort (lowest priority)

    Multilingual Support: Keywords are automatically provided in German (DE), French (FR), Italian (IT), and English (EN) when available from the source vocabularies.

    Semantic URIs: Each keyword includes its original URI from the source vocabulary for semantic web compatibility.

    Synonym Discovery & Related Terms

    This tool dynamically discovers synonyms and related terms using multiple intelligent sources:

    • OpenAI (ChatGPT): Primary source using GPT-3.5-turbo to generate contextually relevant German synonyms and related terms, validated against authoritative vocabularies.
    • Wikidata relationships: Uses semantic properties like "subclass of", "part of" and aliases to find related concepts from the world's largest linked-data knowledge base.
    • TERMDAT analysis: Finds related terms in the same Swiss Federal terminology collections and analyzes definitions for semantic similarity.
    • Quality validation: All AI-generated candidates are verified against Wikidata and TERMDAT before inclusion; fallback to linked-data discovery if AI is unavailable.

    Process: The system first asks ChatGPT for synonyms, validates them against authoritative sources, and falls back to semantic analysis if needed. Results discovered via synonym search are marked in the UI (green indicator).
